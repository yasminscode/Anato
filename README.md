# Anatomia Prática 2 — Ombro, dorso e plexo braquial

Site estático, sem dependências externas. Tem 14 questões: 2 para cada referência numerada (1–7), com identificação e alternativas múltiplas.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` e a pasta `images/`.
3. Abra **Settings → Pages**.
4. Em Build and deployment, escolha deploy from a branch, branch `main` e pasta `/ (root)`.
5. Salve e abra o endereço gerado.

## Nota sobre as imagens
O arquivo RAR foi recebido, mas neste ambiente apenas quatro das imagens puderam ser extraídas. Para não atrasar o treino, o site usa recortes das imagens disponíveis para algumas referências. Se você quiser que cada estrutura use exatamente a foto individual original, envie as imagens 1.png e 4 e 5.png separadamente (ou em ZIP).
